# Shortener

Сервис сокращения ссылок на Go. Проект используется как площадка для экспериментов: нагрузочное тестирование, фантомная реклама, система баллов.

## Текущая стадия

- [x] Редирект по короткому коду (`GET /{code}`)
- [x] Создание короткой ссылки (`POST /links`)
- [x] PostgreSQL + пул соединений (pgx)
- [ ] Нагрузочное тестирование
- [ ] Фантомная реклама при переходе по ссылке
- [ ] Личные кабинеты пользователей
- [ ] Начисление баллов за просмотр рекламы

## Стек

- **Go 1.25**
- **PostgreSQL 18**
- **chi** — HTTP-роутер
- **pgx v5** — драйвер PostgreSQL

## Запуск

### Только база данных (сервис локально)

```bash
docker-compose up -d
go run ./cmd
```

### Полностью в Docker

```bash
docker-compose -f docker-compose.full.yml up --build
```

## API

### `POST /links`

Создать короткую ссылку.

**Тело запроса:**
```json
{
  "original_url": "https://example.com"
}
```

**Ответ `201`:**
```json
{
  "short_code": "aB3xYz"
}
```

### `GET /{code}`

Редирект на оригинальный URL. Возвращает `301` или `404`.

### `GET /health`

Healthcheck. Возвращает `200`.
